# User Guide: Advanced Search

Use Advanced Search to find books with multiple filters at once.

## Open Advanced Search

1. Open the app.
2. Go to `Search`.
3. Tap `Advanced Search`.

## Available filters

- `Text`: matches title, description, and author.
- `Authors`: multi-select one or more authors.
- `Categories`: multi-select one or more categories.
- `Duration`: choose a duration range.

You can use any combination of filters.

## How matching works

- Filters use **AND logic**.
- A book must satisfy all selected filters to appear.
- If no filters are selected, all books are eligible.

## Examples

- Find short books by one author:
1. Select one author.
2. Set duration to `<30`.
3. Tap `Apply Filters`.

- Find long books in a category with text:
1. Enter text (for example `history`).
2. Select one or more categories.
3. Set duration to `300+`.
4. Tap `Apply Filters`.

## Tips

- Start with one filter, then add more to narrow results.
- If no results appear, remove one filter at a time.
- Use text search for partial matches.
