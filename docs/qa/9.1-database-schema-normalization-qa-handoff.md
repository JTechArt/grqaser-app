## Overview

This story implements database schema normalization by creating separate tables for authors and categories, eliminating data duplication and enabling efficient filtering for Epic 9's advanced search features.

---

## What Changed

### New Tables Created
1. **`authors`** - Stores unique author names
   - Columns: id, name, created_at, updated_at
   - Index: idx_authors_name

2. **`book_categories`** - Stores unique category names
   - Columns: id, name, created_at, updated_at
   - Index: idx_categories_name

### Books Table Updated
- Added `author_id` (INTEGER, references authors.id)
- Added `category_id` (INTEGER, references book_categories.id)
- Original `author` and `category` columns preserved for backward compatibility
- New indexes: idx_books_author_id, idx_books_category_id, idx_books_duration, idx_books_author_category

### Migration Scripts
- `books-admin-app/src/migrations/001-normalize-authors-categories.js`
- `books-admin-app/scripts/run-migration-001.js`
- `books-admin-app/scripts/rollback-migration-001.js`
- `books-admin-app/scripts/verify-migration-001.js`

### Test 3: Database Queries ✅

**Objective:** Verify JOIN queries work correctly

**Test Queries:**
```bash
# Query 1: Books with author and category names
sqlite3 data/grqaser_qa_test.db "
SELECT b.id, b.title, a.name as author, c.name as category 
FROM books b 
LEFT JOIN authors a ON b.author_id = a.id 
LEFT JOIN book_categories c ON b.category_id = c.id 
LIMIT 10;
"

# Query 2: Top authors by book count
sqlite3 data/grqaser_qa_test.db "
SELECT a.name, COUNT(*) as book_count 
FROM books b 
JOIN authors a ON b.author_id = a.id 
GROUP BY a.id 
ORDER BY book_count DESC 
LIMIT 10;
"

# Query 3: All categories
sqlite3 data/grqaser_qa_test.db "
SELECT id, name FROM book_categories ORDER BY name;
"

# Query 4: Books by specific author
sqlite3 data/grqaser_qa_test.db "
SELECT b.title 
FROM books b 
JOIN authors a ON b.author_id = a.id 
WHERE a.name = 'Ջեկ Լոնդոն' 
LIMIT 5;
"
```

**Expected Results:**
- ✅ All queries execute without errors
- ✅ Results show correct author/category names
- ✅ No broken joins (NULL where data should exist)
- ✅ Counts match expectations

**Pass Criteria:**
- All queries return results in < 1 second
