# Story 12.5: UI — Batch history list and detail

## Status

Done

## Story

**As an** administrator,  
**I want** to see a list of all download batches (Part 1, Part 2, …) with summary info, and drill down to see full details for each batch,  
**so that** I know what was downloaded, where, and how long it took.

## Acceptance Criteria

1. Batch history list: shows all batches in reverse chronological order.
2. Each batch row: batch ID/part number, base folder path, status (completed, paused, cancelled), books downloaded count, total size (GB), duration, started_at, completed_at.
3. Batch detail view: expand or navigate to see full history for that batch.
4. Detail shows: list of books with title, author, folder path, size, duration, status.
5. Detail shows: batch summary (path, duration, any errors if failed books exist).

### Refactoring Performed

- **File**: `books-admin-app/public/index.html`
  - **Change 1**: Fixed ID mismatch — JS referenced `downloadBatchesList` and `refreshDownloadBatchesBtn` but HTML uses `batchesList` and `refreshBatchesBtn`. Changed JS to use correct IDs so batch list loads and Refresh button works.
  - **Change 2**: Call `loadDownloadBatches()` when Download view is shown. Previously batch history never loaded on tab switch; only loadDownloadStatus and startDownloadPolling were called.
  - **Change 3**: Update `batchesCount` when batches load (e.g. "3 batches") for consistency with other list views.
  - **Why**: Without these fixes, batch history would not display; Refresh would fail silently; count would stay "0 batches".
  - **How**: Use getElementById('batchesList') and getElementById('refreshBatchesBtn'); add loadDownloadBatches() in showView when viewId === 'download'; set countEl.textContent in loadDownloadBatches.
