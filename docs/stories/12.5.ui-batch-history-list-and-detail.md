# Story 12.5: UI — Batch history list and detail

## Status

Draft

## Story

**As an** administrator,  
**I want** to see a list of all download batches (Part 1, Part 2, …) with summary info, and drill down to see full details for each batch,  
**so that** I know what was downloaded, where, and how long it took.

## Acceptance Criteria

1. Batch history list: shows all batches in reverse chronological order.
2. Each batch row: batch ID/part number, base folder path, status (completed, paused, cancelled), books downloaded count, total size (GB), duration, started_at, completed_at.
3. Batch detail view: expand or navigate to see full history for that batch.
4. Detail shows: list of books with title, author, folder path, size, duration, status.
5. Detail shows: batch summary (path, duration, any errors if failed books exist).

## Dev Notes

### Context

Epic 12 MP3 bulk download. Story 12.3 provides GET /batches and GET /batches/:id; this story implements the history list and detail UI ([Source: docs/feature-requests/mp3-bulk-download-admin.md]).

### Batch list display

- Batch ID / Part number (e.g. "Part 1", "Part 2", or batch-{uuid})
- Base folder path
- Status: completed, paused, cancelled
- Books downloaded count
- Total size in GB
- Duration (formatted, e.g. "2h 15m")
- Started at / Completed at (formatted dates)

### Batch detail display

- Full download history for that batch
- Books: title, author, folder path, size, duration, status
- Where it was downloaded (path)
- How long it took
- Any errors (if failed books exist)

### File locations

- `books-admin-app/public/` — add batch history list and batch detail views
- Integrate with Download section from Story 12.4

### Design system

- Same as Story 12.4: docs/design/README.md, docs/design/books-admin-app/

### Compatibility

- No regression in existing UI. Additive only.

### Testing

- Manual: verify list loads, detail shows correct book data. Optional: basic UI tests.
