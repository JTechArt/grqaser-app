# Story 12.4: UI — Download setup and active download progress

## Status

Done

## Story

**As an** administrator,  
**I want** a UI to select the download folder, set max size, start the download, and see real-time progress (phase, book, part, size, time),  
**so that** I can initiate bulk downloads and monitor them without the UI feeling stale.

## Acceptance Criteria

1. Folder selection control: admin selects base folder for download (absolute or relative path; platform-dependent).
2. Max size input: configurable max size per batch (default 200GB); shown in GB.
3. Start download button: validates folder writable, starts batch, navigates or shows active download view.
4. Real-time progress display: current phase (1/2/3), "Writing metadata for book X of Y" or "Downloading book X of Y — part Z of W".
5. Running totals: books completed, total size downloaded, elapsed time.
6. Storage limit display: "X GB / 200 GB" with progress bar; warning when near limit.
7. Pause reason: when auto-paused (e.g. storage limit), show "Paused: storage limit reached".
8. Cancel button: admin can cancel running batch.
9. UI updates frequently (SSE, WebSocket, or polling every 1–2 seconds) so progress does not feel stale.
