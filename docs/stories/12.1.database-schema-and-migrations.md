# Story 12.1: Database schema and migrations

## Status

Draft

## Story

**As a** developer,  
**I want** new database tables (`admin_downloaded_books` and `admin_download_batches`) to track MP3 bulk download batches and per-book download progress,  
**so that** the download pipeline and UI can persist batch history, progress, and status.

## Acceptance Criteria

1. New table `admin_downloaded_books` exists with columns: id, book_id, download_batch_id, local_folder_path, total_size_bytes, part_count, parts_downloaded, status, started_at, completed_at, error_message.
2. New table `admin_download_batches` exists with columns: id, base_folder_path, max_size_bytes, status, books_downloaded, total_size_bytes, started_at, completed_at, duration_seconds, config_json.
3. Migration script creates both tables; migration is reversible (down migration or documented rollback).
4. Tables reference the active database used by books-admin-app.
5. book_id references books.id; download_batch_id references admin_download_batches.id.

## Dev Notes

### Context

Epic 12 adds MP3 bulk download to books-admin-app. This story creates the persistence layer for tracking download batches and per-book progress ([Source: docs/feature-requests/mp3-bulk-download-admin.md]).

### Schema Reference (from feature request)

**admin_downloaded_books:**

| Column | Type | Notes |
|--------|------|-------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT |
| book_id | INTEGER | NOT NULL; references books.id |
| download_batch_id | TEXT | NOT NULL; e.g. batch-{uuid} |
| local_folder_path | TEXT | NOT NULL |
| total_size_bytes | INTEGER | Sum of MP3 sizes |
| part_count | INTEGER | 1 for single-file; chapter_count for multi-chapter |
| parts_downloaded | INTEGER | Completed parts count |
| status | TEXT | pending, in_progress, completed, failed, paused |
| started_at | TIMESTAMP | |
| completed_at | TIMESTAMP | NULL if failed/paused |
| error_message | TEXT | NULL; set if failed |

**admin_download_batches:**

| Column | Type | Notes |
|--------|------|-------|
| id | TEXT | PRIMARY KEY; e.g. batch-{uuid} |
| base_folder_path | TEXT | NOT NULL |
| max_size_bytes | INTEGER | NOT NULL; e.g. 200GB |
| status | TEXT | preparing, downloading, paused, completed, cancelled |
| books_downloaded | INTEGER | Count completed |
| total_size_bytes | INTEGER | Running sum |
| started_at | TIMESTAMP | |
| completed_at | TIMESTAMP | |
| duration_seconds | INTEGER | Computed or stored |
| config_json | TEXT | JSON: book IDs, pipeline phase, etc. |
